# Fouché Motors – proof of concept

One-page CRO microsite for Fouché Motors (pre-owned exotics, Sandton), built on the CA Microsites automotive template (Jean's fork).

- **Live:** GitHub Pages, deployed from the `main` branch, root folder.
- **Stock:** 119 listings crawled from fouchemotors.co.za on 12 Oct 2026.
- **Forms:** mockup only, nothing is sent.
- **Editing:** don't edit this `index.html` by hand. It's the launch export, with the editor removed. Make changes in the working copy (the Claude artifact, or `builds/fouche-motors` in Drive), export the launch files again and replace the files here.
